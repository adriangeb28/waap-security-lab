# WAAP Defense Lab 2026

Prototipo académico de **WAAP + detección de anomalías + RASP + DevSecOps** para el Taller No. 1. La organización y los componentes fuerron reestructurados respecto de una implementación de referencia: la aplicación objetivo es una pequeña aplicación Flask vulnerable para laboratorio, el RASP está embebido como middleware Python, y el detector ML usa un conjunto de características distinto.
